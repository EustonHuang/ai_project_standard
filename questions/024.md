## Q24 — 2026-10-05
**问题：** 假设我有一个新的项目，想要运用这个项目规范框架，我应该怎么做？有什么命令或者指示使得我能够在新的项目中"安装"这个项目规范？

**答案：**

- **定位**：本框架是 metastandard（元标准），不是 CodeBuddy skill。采用方项目不拷贝规范文档，只持有一个版本指针（`standard_version` 锁文件）+ 一份引擎拷贝（`.plan-standard/`）+ 项目级 hook。
- **前置**：本地需有框架仓库（`git@github.com:EustonHuang/ai_project_standard.git`，本地 `/Users/euston/personal/ai_project_standard`）。
- **安装（copy 模式）**：
  `python3 /Users/euston/personal/ai_project_standard/scripts/standard_ops.py install --version v0.4 --project /path/to/your/project`
  参数：`--version vX.Y|latest`（默认 latest）、`--pinned latest|<ver>`、`--framework <path>`（默认即框架仓库）；`--self` 仅框架仓库自举用，新项目不要加。
- **安装实际做的 4 件事**：① 把 `scripts/ references/ assets/` 经 `git archive <tag>` 拷到 `<project>/.plan-standard/`（按 tag 锁版本，项目自包含）；② 写 `standard_version` 锁文件；③ 写 `.codebuddy/settings.json` 挂三个 hook（`UserPromptSubmit→begin` / `PostToolUse(write|edit|delete)→record` / `Stop→end`），均指向 `.plan-standard/scripts/turn_gate.py`，并设 `PLAN_HISTORY_ROOT=$CODEBUDDY_PROJECT_DIR` 限定作用域；④ 调 `append_history.py init` 建 `history/ questions/ issues/ improvements/ architecture/` + 五份 `*_index.json` + TOC。
- **安装后必须做的第一件事**：把"采纳标准"本身记成一条 `plan_modified` 事件写进 `history/`，否则 Stop hook 会判定本轮改动未入账而 `exit 2` 拦住。
- **日常 / 后续命令**：
  - 记录事件 / 提问 / 改进：`append_history.py append --plan <proj> --event e.json`；`--kind questions --body q.md --question-ref Q1 --question "..." --answer-summary "..."`；`--kind improvement --body i.md --title "..." --priority 3 --status 1`
  - 校验 / 浏览 / 重建：`audit` / `show --plan <proj> --last 20` / `gen-toc --plan <proj> --kind all`
  - 版本：`standard_ops.py check --project <proj>`；`update --project <proj>`（同 major 自动升）；`update --project <proj> --to v1.0 --confirm-breaking`（跨 major 须先人工 review）
- **两个必须注意的点**：① hook 会**整体覆盖**项目已有 `.codebuddy/settings.json` 的 hooks（脚本执行的是赋值而非合并），若项目已有自己的 hook 须先备份、装完手工合并；② `.plan-standard/` 是拷贝而非引用，升级走 `update` 重新拷贝，不要手改其内脚本；老项目若有 `history.json`/`questions.md` 先 `migrate` 再 `audit`。
- 注：`skills/install-standard` 等目前只存在于框架仓库内、未装进 `~/.codebuddy/skills/`，想按名调用需手动拷过去；不拷则直接跑上面的命令，效果一致。
