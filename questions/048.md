## Q48 — 2026-10-24

**问题：**
采用本规范的项目是不是都要更新到 v0.9 才能开 tracing？用旧版本的项目无所谓吗？

**答案：**

开 tracing 需要**两步**，版本只是第一步：

1. **引擎更新到 v0.9**（`update-standard`）——拿到 `session_recorder.py`/`recorder_feed.py` 与 `install-session-recorder` skill（copy 模式随 `copy_engine` 复制到 `.plan-standard/scripts/`）。这只是**拿到能力**。
2. **运行 `install-session-recorder` skill**——真正接线四条 hooks + 注册 watch path + 起 daemon。这才是**打开开关**。

结论矩阵：

| 项目状态 | tracing | 影响 |
|---|---|---|
| 旧版本（≤ v0.8），未更新 | 无能力（脚本不在引擎里） | 零影响，v0.9 非 breaking；「无所谓」成立 |
| 更新到 v0.9，未跑 skill | **不录**（opt-in：settings.json 不动、audit 不变） | 零行为变化 |
| 更新到 v0.9 + 跑 skill | 该项目全部 session 全录 | 独立决策 |

- **版本决定「能不能开」，opt-in 决定「开不开」**；每个项目独立决策，互不影响。
- 旧版项目连 `check-standard` 的「recorder 未接线」提醒都看不到（检查代码本身 v0.9 才有）——提醒随更新而来，旧版不会被催促。
- daemon 是 per-user 单实例（Q45）：一个项目 opt-in 不影响其他项目；多项目各自 opt-in 后共用同一 daemon，按 `(plan_id, session_id)` 分文件。
